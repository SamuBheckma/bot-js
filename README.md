# Bot Discord - Execução de Código JavaScript

Este bot permite executar código JavaScript diretamente no Discord, com suporte para gerenciamento de processos e segurança.

## Funcionalidades
- **Gerenciamento de Processos**: Comando `!kill` para encerrar execuções travadas.
- **Segurança**: Apenas o administrador pode executar comandos perigosos.

## Comandos
### `compile`
Executa código JavaScript.
- **Exemplo**: ```js console.log("Olá, mundo!");```

### `!kill`
Encerra um processo em execução.
- **Exemplo**: `!kill <ID da mensagem>`
